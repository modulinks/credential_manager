🔐 Gestor de Credenciales

Módulo profesional de gestión de credenciales para Odoo 16

🚀 Administración Segura de Credenciales

Este módulo permite gestionar credenciales de forma segura al estilo de cualquier autenticador de doble factor, directamente integrado en Odoo 16. Diseñado para equipos técnicos que necesitan centralizar y controlar el acceso a credenciales críticas.

Odoo 16 Community & Enterprise Multi-Usuario 2FA SSH Ready
🔒

Gestión Segura

  • Almacenamiento cifrado de contraseñas
  • Control granular de permisos por grupos
  • Campos ocultos para información sensible
  • Botones de mostrar/ocultar contraseñas
  • Funcionalidad de copiado al portapapeles
🛡️

Autenticación 2FA

  • Integración con Google Authenticator
  • Generación automática de tokens TOTP
  • Verificación obligatoria para accesos críticos
  • Secretos 2FA protegidos por permisos
  • Tokens con validez de 30 segundos
💻

Soporte SSH Completo

  • Credenciales SSH para usuarios regulares
  • Accesos SSH Root separados
  • Gestión de claves privadas
  • Configuración de IP, DNS y puertos
  • Campos específicos para desarrolladores
📁

Organización Avanzada

  • Sistema de colecciones/carpetas
  • Control de acceso por grupos de Odoo
  • Múltiples URLs por credencial
  • Campo de notas para documentación
  • Seguimiento de cambios (chatter)
👥

Control de Acceso

  • Grupo Administradores de Credenciales
  • Grupo Consultores (acceso limitado)

  • Restricciones basadas en roles

Funcionalidades Técnicas

  • Interfaz responsive y moderna

⚠️ Consideraciones de Seguridad

Importante: Este módulo está diseñado para uso interno en equipos técnicos. Asegúrate de:

  • Configurar correctamente los grupos de seguridad
  • Usar HTTPS en producción
  • Realizar backups regulares de la base de datos
  • Auditar regularmente los accesos y permisos
  • Mantener actualizado el sistema Odoo

📦 Instalación

Para instalar este módulo en tu instancia de Odoo 16:

# 1. Copia el módulo en tu directorio de addons cp -r credential_manager /path/to/odoo/addons/ # 2. Instala la dependencia pyotp pip install pyotp # 3. Reinicia el servidor Odoo sudo systemctl restart odoo # 4. Actualiza la lista de módulos en Odoo # 5. Instala el módulo "Gestor de Credenciales"

Dependencias requeridas:

  • Python package: pyotp (para 2FA)
  • Módulos Odoo: base, mail
